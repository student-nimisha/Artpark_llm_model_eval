# Multilingual LLM Evaluation Framework

A configurable framework for evaluating multilingual Large Language Models on Indic benchmark datasets.

## Features

- Configuration-driven experiments
- Multiple LLM support
- HuggingFace dataset streaming
- Prompt-based evaluation
- Automatic metric computation
- Easily extensible

Current Version

- Transcript input
- Gemma 3
- Aya Expanse
- Profanity Detection
